# Grimoire: a deep-brown, dithered retheme for tinksoft.com

Date: 2026-11-18. Status: draft for approval. Nothing here is built yet.

## What and why

tinksoft.com today has a teal-and-purple terminal look on parchment (day) or near-black (night). The owner wants it warmer and more distinctive without losing what makes it feel retro: the monospace terminal chrome, the `[bracket]` nav, the system bar, the telemetry, plain HTML, and 0 KB of JavaScript.

The new look is called **Grimoire**. Each color scheme gets its own role:

- **Night is a dungeon screen.** Deep brown-black, torch orange, gold frames. The masthead is a framed viewport looking down a torchlit stone corridor, drawn in Bayer-dithered pixels. The feel is a 1980s first-person dungeon crawler.
- **Day is a rulebook page.** Umber parchment, near-black ink, red rubrication. The same corridor is drawn as an ink engraving. The feel is a well-thumbed late-'80s fantasy wargame rulebook ("Oldhammer").

It belongs to the same family as Skyhopper's Ember theme and CIPHER's Ditherfield redesign. It takes their ordered-dither language (Bayer 8×8 art, 2×2 checker textures, hard edges, no blur) and their warm palette, but none of their code.

This is a style homage. All art is original: the corridor is generated by our own script. No frames, logos, fonts or screens from any existing game or publisher are copied.

### Mockups

The approved mockups live in the git-ignored brainstorm folder. They're reference only, not code to copy:

- `.superpowers/brainstorm/1520-1795055551/content/deep-brown-v4.html`: masthead, wordmark, home page, ornaments. **This is the approved look.**
- `deep-brown-v2.html` in the same folder: the post page, the type pairings, and the projects roster idea.
- `gen-corridor.cjs` in the same folder: the throwaway generator for the corridor and strips. The build script ports it (see Assets).

## Goals

1. Night (dungeon) and day (rulebook) palettes, chosen by `prefers-color-scheme` as today. There is no toggle and no JS.
2. The torchlit dithered corridor in the masthead, in both schemes. **This is the centerpiece and is not optional.**
3. A blackletter **TinkSoft** wordmark replaces the ASCII logo.
4. A type system:
   - blackletter display type for big headings;
   - pixel type for section labels;
   - an old-style serif for titles and reading text;
   - monospace for the terminal chrome.
5. Every link highlight (hover and keyboard focus) is readable on every page.
6. The site stays inside its limits: 14 KB gzipped per HTML page, 0 KB JS, no third-party requests.

## Non-goals

- No scheme toggle, theme switcher or any script.
- No copy changes. Section labels keep today's plain wording. The mockup's "flavor" labels ("a new scroll lies here") are **not** included.
- No new pages or content-model changes. The projects roster (see Pages) is built only from data the page already loads.
- The `.nfo`, `FILE_ID.DIZ` and other text files keep the ASCII logo. It belongs there.

## Anti-goals

These would make it a failure even if it technically works:

- **Hard to read.** Body text, titles and links must read at least as well as today. Dither texture never sits directly behind small text.
- **Costume over content.** No fantasy flavor text, no parchment-scroll clip-art, no fake-aged blur.
- **Broken without fonts.** If the web fonts fail, the site must still look intentional, using the serif and mono fallbacks.
- **Motion that ignores people.** Anything that moves stops under `prefers-reduced-motion`.
- **Budget creep.** A theme that pushes ordinary posts close to the 14 KB limit.

## Constraints

- **Page budget.** `scripts/size-gate.mjs` fails any HTML page over 14,336 bytes gzipped. The heaviest page today is 6,959 B (`/log/signal-2026-06-12/`).
- **Security policy.** The meta CSP is `default-src 'none'; style-src 'unsafe-inline'; img-src 'self' data:`. Self-hosted fonts need `font-src 'self'` added. Nothing else changes.
- **Build validator** (`scripts/validate-build.mjs`):
  - Exactly one `<h1>` per page, so the wordmark must not be an `<h1>`.
  - No executable `<script>`.
  - Every local `href`/`src` must resolve to a file in `dist/`, so a font `<link rel="preload">` must point at a real file.
  - `data:` URLs are allowed only as `data:image/…` on `<img>`/`<link>`. CSS custom properties in a `style` attribute aren't checked.
- **Astro.** `build.inlineStylesheets: 'always'`, and scoped styles use attribute selectors, so a page's `.tags a { … }` outranks a global `a:hover`. That causes the highlight bug below.
- **Contrast.** WCAG AA: 4.5:1 for text, 3:1 for large text and UI boundaries. `docs/accessibility-review.md` records the last review.
- **Fonts** must be OFL-licensed and self-hosted, with their license shipped alongside.

## Approaches

### How to get the art on the page

| Approach | Cost per page (gzip) | Verdict |
|---|---|---|
| A. CSS-only chrome: checker textures and palette, no scene | about +0.3 KB | Rejected. It loses the corridor, which the owner explicitly wants. |
| **B. Pre-rendered dither art inlined as `data:` PNGs, plus CSS checker chrome** | about +3.6 KB of art, plus CSS growth | **Chosen.** The art appears with the first paint, with no extra request. It keeps the "one document, one TCP window" idea. |
| C. The same art as separate cached image files | about +0.4 KB, plus 1–4 requests on a first visit | Kept as the escape hatch if the budget gets tight (see Size budget). |

Also rejected:
- Running CIPHER's canvas renderer: 23 KB of JS, and it breaks the CSP.
- An SVG-filter dither: tiny, but rendering differs between browsers.
- The earlier "Hearth" gradient sky: less dithered, and the logo was illegible on it at night.

### Type

| Pairing | What it is | Verdict |
|---|---|---|
| Terminal | Today: monospace everywhere | Rejected. Not warm enough. |
| Rulebook | System old-style serif for titles and prose, mono chrome. 0 KB | Rejected by the owner in favor of more character. It's still the fallback when fonts fail. |
| **Grimoire · gothic** | Rulebook, plus Grenze Gotisch for display and Silkscreen for section plates | **Chosen by the owner.** |
| Grimoire · fell | IM Fell English everywhere, plus Silkscreen | Rejected. Heaviest, and rough at body size. |

- **Contrast,** measured in the mockup:
  - At night every text pair is at least 4.5:1 on `--bg` and `--panel`.
  - By day, everything passes except `--rubric` on `--bg` at 4.4:1. That color is only used for large initials, where 3:1 applies.
  - **Day `--panel-2` must never sit behind text.** Muted text and links drop to about 4.1:1 there, so day hover tints use `--panel`.

### Textures and art

All art follows CIPHER's rule:
- Every pixel is an opaque palette color or transparent.
- There is no alpha blending and no blur.
- Everything is rendered at an integer scale with `image-rendering: pixelated`.

- **Top strip.** Replaces `body::before`'s 4-color bar. It's a 16×14 tile, dithered from bright ember into `--bg` at night (from ink into `--bg` by day), shown at 2× (28px tall), repeated across the full width.
- **The corridor.** A 120×80 Bayer 8×8 ray-cast of a stone corridor: block walls, flagstone floor, beamed ceiling, an arched doorway into darkness at the far end, and one torch on each side wall. It's shown at 2× (240×160) inside a 3px double `--gold` frame with a 2px `--shadow` ring.
  - **Night:** 8 colors (`#0b0704 #22130a #3d2210 #663818 #9a5523 #cf7b2e #f0ac55 #ffe3a3`), with distinct flames. The 4-color variant isn't used.
  - **Day:** a 3-tone engraving with sepia `#6b4a2a`, ink `#1e140b` and red `#7e1a10` flames. Paper is transparent; the viewport's backing color, `--panel-2`, shows through, as in the mockup.
- **Torch flicker (night only).** Two hard-edged dithered halos, one per flame: sparse `#ffc66b` dots masked by a hard circle. Each steps between radii with `steps(1)` timing, on 1.9 s and 2.3 s cycles, offset from each other. That's never more than 3 changes a second. The halo positions must match the flame positions the generator uses.
- **Dithered rules.** Rules are 2px or 4px checkers in `--gold`. They replace `.footer-rule`'s gradient and `<hr>`.
- **The pixel diamond (`.gem`).** The site's one ornament. It's a 5×5-pixel diamond drawn with one element plus `box-shadow` "pixels" (3px pixels, or 2px for the small variant), with `--gold` edges and a `--torch` core (`--rubric` by day). It replaces every fleuron (❦ ☙ ❧): **no Unicode ornament glyphs anywhere**, because they render differently on every system and the owner disliked them.
  - **Section divider:** a dithered rule, a diamond, then a dithered rule.
  - **Footer top:** a dithered rule, then small, large and small diamonds, then a dithered rule.

### Type

| Role | Font | Where |
|---|---|---|
| Display | **Grenze Gotisch 700** (blackletter), with fallback to the serif stack | wordmark, page `<h1>`, prose `<h2>`, drop caps |
| Plates | **Silkscreen 400** (pixel), **16px only** (multiples of 8 stay crisp), uppercase; fallback to mono bold uppercase | section labels: `.scene-label`, `.module-header h2`, `.panel-title h2` and the like |
| Titles and prose | `"Iowan Old Style", "Palatino Linotype", "Book Antiqua", Palatino, "URW Palladio L", P052, Georgia, serif` (system, 0 KB) | post and project titles in lists, `.lede`, prose, blockquotes, descriptions, tagline (italic) |

- **Sizes:**
  - wordmark: `clamp(48px, 6.6vw, 84px)`, line-height 0.98;
  - `<h1>`: 54px on desktop, scaling down on phones (the builder picks the clamp);
  - post title: about 0.82 of that;
  - prose: 17.5px/1.62;
  - list titles: 18–21px bold serif;
  - plates: 16px;
  - chrome: today's mono sizes.
- **Never use blackletter in all caps.** The wordmark is "TinkSoft", not "TINKSOFT". The system bar keeps the all-caps mono "TINKSOFT // PUBLIC NODE 01".
- **Loading:** `@font-face` with `font-display: swap`. Preload Grenze Gotisch on every page with `<link rel="preload" href="/fonts/grenze-gotisch-700.woff2" as="font" type="font/woff2" crossorigin>`, because every page's `<h1>` and the wordmark use it. Without `crossorigin` the preload is wasted. Silkscreen isn't preloaded. Set `font-synthesis: none` on the display face, since there's only one weight.

### Links and highlights (the readability fix)

**Requirement.** Every link, on `:hover` and on `:focus-visible`, renders in `--hi-ink` on `--hi-bg`, with no underline and a 2px `--hi-bg` spread so there's no layout shift. Keyboard focus adds a second 2px ring in `--hi-ink`. Contrast is 8.5:1 at night and 13.1:1 by day.

**Why it breaks today.** Astro scopes page styles with attribute selectors, so `.tags a` (for example `archive.astro:138`) outranks the global `a:hover`. Hovering paints the highlight background behind text that keeps its own color, and the link disappears. The mockup hit the same problem with title links: ink text on an ink background.

**Mechanism (recommended).** One global rule sets `color` and `background-color` with `!important` on `a:hover, a:focus-visible`. It's the site's only intentional use of `!important`, and it should carry a comment saying why. Two consequences:

- **The wordmark is unaffected.** Its text fill is transparent, so it ignores `color`, and its opaque gradient covers `background-color`. Verify this in the browser; the mockup couldn't test hover with a real pointer.
- **Block links' children must inherit while highlighted.** When a whole card is a link and a child sets its own color, that child must use `color: inherit` during the highlight. Known block links:
  - `.link-card` (links page)
  - `.project-actions a` (project page)
  - `.tag-grid a` (tags index)
  - `.card-actions a`, `.primary-action` (projects index)
  - `nav.post-nav` links
  - `.tag-row a` (post)
  - `.index-status a`, `.text-link` (home)
  - `.action`

### Motion

- Only the torch flicker moves, and only at night.
- Under `prefers-reduced-motion: reduce` it stops on its resting frame.
- The demo page keeps its own animations and pause toggle.
- Nothing else animates, and there are no transitions on colors.

### Accessibility

- **The wordmark is real text.** That's better than today's `aria-hidden` ASCII. The initial's span doesn't break how screen readers announce it.
- **The corridor is decorative:** a CSS background with no role or label.
- **Forced colors (Windows high contrast).** `background-clip: text` with a transparent fill would make the wordmark invisible. Under `@media (forced-colors: active)` the wordmark must set `-webkit-text-fill-color: currentColor`, `background: none` and `filter: none`. Plates and highlights fall back to system colors on their own.
- **Font fallback.** With web fonts blocked, headings fall back to the serif stack and plates to bold mono uppercase. Both were checked in the mockup and look intentional.
- **New review.** `docs/accessibility-review.md` gets a new review entry after the build, covering contrast in both schemes, keyboard focus on every block link, reduced motion and forced colors.

## Assets and build

- **`scripts/dither-art.mjs`** (new) is an ES-module port of the mockup's `gen-corridor.cjs`. It's deterministic, uses no dependencies (only `node:zlib`), and writes indexed PNGs: night corridor (4-bit), day corridor (2-bit with `tRNS`), night strip and day strip.
  - It writes a committed module, for example `src/generated/dither-art.mjs`. The module exports each image as a `data:image/png;base64,…` string, plus the torch positions as percentages, so the flicker CSS isn't full of magic numbers.
  - It isn't part of `npm run build`. It's run by hand when the art changes.
- **Tests** (`node --test`):
  - Running the generator reproduces the committed module byte for byte (no drift).
  - Each PNG has a valid signature.
  - Each image stays under a ceiling: night corridor ≤ 2,048 B and day ≤ 1,536 B raw PNG (measured 1,882 and 1,262), strips ≤ 256 B each.
- **Inlining.** `Base.astro` puts the art into the page without an extra request. For example, it can set custom properties in the `<html>` element's `style` attribute (`--scene-night`, `--scene-day`, `--strip-night`, `--strip-day`), which the global CSS picks between by color scheme. Any inline mechanism is fine as long as it adds no request and passes the validator.
- **Fonts:**
  - `public/fonts/grenze-gotisch-700.woff2` and `public/fonts/silkscreen-400.woff2`, Latin subset, plus `public/fonts/OFL.txt` and a note recording the source and version. Fontsource's Latin woff2 files or the Google Fonts repository are both fine.
  - Targets: ≤ 25 KB for Grenze (Google currently serves its whole variable font at 41 KB) and ≤ 10 KB for Silkscreen (8.2 KB today).
  - Add `font-src 'self'` to the CSP meta.
- **Hard-coded teal to repaint:**
  - The favicon `data:` URI (`Base.astro:85`) and `public/favicon.svg` become the pixel diamond on `--bg`, with a light and dark variant like today.
  - The `theme-color` metas (`Base.astro:101-102`).
  - `public/counter.svg`: an amber CRT readout in both schemes.
  - `public/badge.svg` (the 88×31 button): brown, gold and ember, still monospace, because SVG images can't load web fonts.
- **Copy that describes the site, to update:**
  - README "The numbers": still 2 requests per page (the document and `counter.svg`), plus two cached font files on a first visit. The art stays inline. The font claim changes too.
  - The colophon's "requests" row and its "system monospace font" sentence (`colophon.astro:34`, `:57`).
  - Any matching line in `src/content/projects/tinksoft-site.md`.
  - The "0 KB JavaScript" claim stays true.

## Size budget

| | Heaviest page, gzip |
|---|---|
| Today | 6,959 B |
| + night corridor | + 1,930 B |
| + day corridor | + 1,308 B |
| + two strips | + 378 B |
| + CSS growth (estimate) | + 1,000–1,500 B |
| **Expected heaviest** | **about 11.6–12.1 KB of 14.0 KB** |

That leaves about 2 KB of headroom for long posts. If a future post trips the gate, there are two escape hatches:

1. Move the corridors into cached `/art/*.png` files (approach C), which frees about 3.2 KB per page.
2. Drop the day engraving and show the night corridor in both schemes.

Font files don't count toward the per-page budget, because they're separate cached requests.
