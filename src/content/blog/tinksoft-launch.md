Tinksoft.com is live. It is my personal site.

## what is here

- [Posts](/) contain notes on software, security, games, and other interests.
- [Projects](/projects/) tracks things I have built or am still working on.
- [Now](/now/) is a short list of current work and reading.
- [Links](/links/) contains sites I use or want to remember.

## how it works

The site is static HTML generated from markdown. CSS and the favicon are
inlined. The only additional page request is the decorative counter image.
There is no client-side JavaScript, analytics, or tracking.

An [RSS feed](/rss.xml) is available.
