A busy stretch. Two ports shipped, one scanner started, and the long-running
rewrites kept composing.

## screech

[Screech](https://github.com/tinkthemaker/screech) spent the week on discovery
radio. RADIO now lists the stations it finds as you type, and every song says
why it was chosen and where it lives. Song facts — length, place, reason, page,
successor — reach the player faces, a cancelled search no longer kills
radio-browser's server, and a reconnect picks a song up where it stopped.
Screech also notices when yt-dlp is old and `screech update-ytdlp` fixes it.

## tping

[TPing](/projects/tping/) is no longer Go. The whole utility is ported to .NET
10 WinForms and ships as a self-contained `tping-gui.exe` — the target machine
does not need the runtime installed. Store tabs borrow the browser pattern,
colour themselves by health, got a smoother new-tab flow, and there is a
colourblind palette. The Go tree stays in the repo as the reference it was
ported from.

## snailbrief

[SnailBrief](https://github.com/tinkthemaker/snailbrief) grew a Brief window:
the daily run saves its cards to disk and opens them in-app, each card can
Show in Outlook, and the connections settings survive upgrades. Saved
credentials now verify and explain themselves, and ticket HTML is converted to
text at the TeamDynamix reads and the KB cache.

## vomit-elegy

New this week: [Vomit Elegy](https://github.com/tinkthemaker/vomit-elegy), a
Kalshi market-coherence engine in C#. It reads public market data, builds
portfolios from exchange-declared payoff constraints, and logs only what it
can prove — there is a dedicated post about it.

## necrotrachea

[necrotrachea](https://github.com/tinkthemaker/necrotrachea) was gorename until
Sunday. It is a random metal-and-gore name generator with theme banks pulled
from web corpora, a `--theme` flag, an ordered-dither CSS UI, and a single-file
GitHub Pages front end.

## the rewrites

Two long-running ports kept moving. [super-carnival](https://github.com/thevariableK/super-carnival)
merged dozens of small compositions — monster steps, scroll effects, level
population, class level-ups. [giant-enigma](https://github.com/thevariableK/giant-enigma)
merged C3: stat resolution with provenance and immutable build sessions. Both
are still mid-plan.

That is enough for two weeks.
