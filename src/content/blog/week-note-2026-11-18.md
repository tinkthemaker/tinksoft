Two-thirds of this window went into Skyhopper. The rest was new tools, one
redesign, and a surprising amount of monster AI.

## skyhopper

[Skyhopper](https://github.com/tinkthemaker/skyhopper) had its biggest week
yet. Seven clicks on the About icon unlock **Ember** — a hidden theme with a
dithered palette, a crackling hearth, tiles that glow and fade on a shared
effect clock, and an About page that credits the code by name. Alongside it:
a device report that draws one clickable picture of a store's devices for a
ticket, a layout guard that fails any screen with overlapping controls or text
that does not fit, and tidier run views. Version 2.4.0 territory.

## model picks

New in a day: [Model Picks](/log/model-picks-tray-app/), a ~1 MB Windows tray
app that answers "which OpenRouter model gives the most capability for the
money" before each project. Budget / Half price / Top per category, every
number traced to Epoch AI, Artificial Analysis, or OpenRouter. There is a
post about it.

## love-encryption

[CIPHER](https://github.com/tinkthemaker/love-encryption) went through a full
retheme: a Bayer 8x8 ordered-dither landscape that lives behind the UI, an
ambient FX bridge, a mode-aware chrome, and a `DESIGN.md` that writes down the
look-and-feel philosophy. Now at v8.

## the account-checking bench

Two repos moved on the credential side. `credcheck` gained RSA-encrypted
passwords, proxy groups, and a vetted 190k-line list prep pipeline. `ossuary`
is a list resolver built on vendored registration-flow modules — it answers
"does this address have an account on site X" for ~250 sites, with a Telegram
watcher and an honest write-up of which providers actually separate signal
from noise. Both are local-only for now; no remotes yet.

## odds and ends

- [Trojan-Hymn](https://github.com/tinkthemaker/Trojan-Hymn) mirrors the ARTEX
  lineage after upstream deleted itself — 12 repos, provenance noted, kept

- [super-carnival](https://github.com/thevariableK/super-carnival) kept

- [quantum-seer](https://github.com/thevariableK/Quantum-Seer) started: a WoW

That is enough for two weeks.
