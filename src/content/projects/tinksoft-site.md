The site you're reading right now. The constraint is the point: every page is
a single HTTP request, ships zero JavaScript, and should load instantly on a
phone, a Pentium, or anything in between.

## goals

- Near-zero friction for posting — a new entry is one markdown file
- Single-request pages: CSS and favicon are inlined into the HTML
- Strict Content-Security-Policy with `default-src 'none'`
- RSS for the three people who still use it (the best people)

## current status

Live and under construction, as all good 90s sites permanently are.
